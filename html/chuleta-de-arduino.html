Chuleta de Arduino

Aquí tienes reunido lo que más vas a consultar mientras programas: el pin de cada componente del shield y las instrucciones de Arduino que usas en la unidad. Es para estudiar y para tenerla a mano en clase.

Dos cosas que conviene recordar

  • Los pulsadores del shield tienen una resistencia hacia 5 V: sueltos dan HIGH y pulsados dan LOW.
  • La librería Servo usa el temporizador de los pines 9 y 10: mientras haya un servo, no uses analogWrite en esos dos pines; enciéndelos o apágalos con digitalWrite. El verde del RGB (pin 11) sigue funcionando con PWM.
  • tone() usa el temporizador del pin 11: mientras suena el zumbador, el verde del RGB no se gradúa. Después del pitido, llama a noTone() y repite el analogWrite del verde (o repítelo en cada vuelta de loop()).

Instrucciones

InstrucciónQué hace
pinMode(pin, OUTPUT);En setup(): el pin será una salida (o INPUT, una entrada).
digitalWrite(pin, HIGH);Pone la salida a 5 V (HIGH) o a 0 V (LOW).
digitalRead(pin)Lee una entrada digital: da HIGH o LOW. Los pulsadores del shield dan LOW al pulsarlos.
analogWrite(pin, valor);Solo en pines con ~: valor de 0 (apagado) a 255 (al máximo) por PWM.
analogRead(pin)Lee una entrada analógica (A0 a A5): da un número de 0 (0 V) a 1023 (5 V).
map(valor, 0, 1023, 0, 255)Pasa un número de una escala a otra.
delay(ms);Detiene el programa esos milisegundos.
millis()Milisegundos desde que se encendió la placa (guárdalo en un unsigned long).
tone(pin, frecuencia); · noTone(pin);Hace sonar el zumbador a esa frecuencia (Hz) · lo calla.
Serial.begin(9600);En setup(): abre la comunicación con el ordenador a 9600 baudios.
Serial.println(x);Escribe x en el monitor serie y salta de línea (Serial.print no salta).
#include <Servo.h> · Servo s;Arriba del todo: incluye la librería y crea un servo.
s.attach(A3); · s.write(90);En setup(): el servo está en el conector A3 · lo mueve a 90°.

Estructuras y operadores

Escribe…Para…
if (condición) { … } else { … }Si se cumple la condición, hace lo primero; si no, lo segundo.
while (condición) { … }Repite mientras se cumpla la condición.
for (int i = 0; i < n; i++) { … }Repite n veces, con i de 0 a n − 1.
== != < > <= >=Comparaciones: igual, distinto, menor, mayor, menor o igual, mayor o igual.
&& || !Y, o, no.
void nombre() { … }Define una función propia que no devuelve nada.

Antes de pedir ayuda, comprueba

  • ¿Termina cada instrucción en ;? ¿Están cerradas todas las llaves?
  • ¿Están HIGH, LOW, OUTPUT e INPUT en mayúsculas?
  • ¿Está el pin preparado con pinMode en setup()?
  • ¿Has elegido la tarjeta y el puerto serial en el Arduino IDE (menú Herramientas)?
